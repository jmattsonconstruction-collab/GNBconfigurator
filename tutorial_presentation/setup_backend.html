Create Your Google Sheet and Deploy the Web App Once — Then Never Touch It Again

1.
Go to sheets.google.com and create a new spreadsheet called "GNB Operations"
2.
Click Extensions → Apps Script
3.
Delete the placeholder code and paste in the Code.gs file (from your Drive → GNB_Configurator → apps-script)
4.
Create a second file called "Index.html" and paste in the Index.html file from the same folder
5.
Click the play button next to "setup" and authorize it (this creates your column headers)
6.
Click Deploy → New Deployment → Web App → set access to "Anyone" → Deploy → Copy the URL

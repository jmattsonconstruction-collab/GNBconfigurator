Export a Portable Copy That Works Anywhere Without Setup

How to Export

  1. Open the Admin Panel (gear).
  2. Go to Advanced Configuration.
  3. Click the green "Export Portable HTML" button.
  4. A file named gnb-configurator-2026-05-11.html will download.

Why It's Powerful

  • All Settings Baked In: Prices, products, company name and the webhook URL are embedded.
  • Send It Anywhere: Email, AirDrop, or USB.
  • Zero Setup: Open in a browser and it works immediately.
